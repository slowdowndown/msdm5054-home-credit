# ZHANG Yajing：C 部分建模、交叉验证与调参交接说明

本部分负责 Home Credit Default Risk 项目的模型训练、交叉验证、模型比较与最终模型选择。

C 部分严格复用 A 部分提供的固定数据版本与 80%/20% 划分，并使用 B 部分提供的特征决策结果构建 V1 特征集。模型选择以 ROC-AUC 为主要评价指标。

## 2. 模型开发过程

模型开发从 A 部分 Logistic Regression baseline 开始，并逐步比较 LightGBM、V1 特征工程、交叉验证、正则化和类别权重。

主要结果如下：

| Experiment | Validation | ROC-AUC |
|---|---|---:|
| V0 Logistic Regression | Fixed 80/20 | 0.751239 |
| V0 LightGBM | Fixed 80/20 | 0.759364 |
| V1 LightGBM baseline | Fixed 80/20 | 0.769522 |
| V1 LightGBM baseline | 5-fold CV mean | 0.763755 |
| V1 Regularized LightGBM | 5-fold CV mean | 0.766092 |
| V1 Regularized + class weight | 5-fold CV mean | 0.765550 |
| V1 Regularized LightGBM | Fixed 80/20 | 0.772396 |
| V1 XGBoost | Fixed 80/20 | 0.772394 |
| V1 XGBoost | 5-fold CV mean | 0.767210 |

Regularized LightGBM 的 5-fold CV：

- Mean ROC-AUC: 0.766092
- Std ROC-AUC: 0.002189
- Best iterations: 659, 738, 660, 875, 593
- Mean best iteration: 705

类别权重 `scale_pos_weight` 经交叉验证后没有提升 ROC-AUC，因此最终模型不使用类别权重。

## 3. 最终模型

在完成 LightGBM 建模、交叉验证和正则化实验后，进一步加入
XGBoost 作为另一种 gradient-boosting model 进行公平比较。

XGBoost 使用与 LightGBM 完全相同的 V1 feature representation、
fold-safe preprocessing、five-fold stratified cross-validation
和 ROC-AUC 评价指标，因此两种模型的结果可以直接比较。

XGBoost 在固定 80/20 validation split 上取得：

- ROC-AUC: 0.772394

XGBoost 的 5-fold cross-validation 结果为：

- Fold 1: 0.767116
- Fold 2: 0.764908
- Fold 3: 0.768490
- Fold 4: 0.768884
- Fold 5: 0.766653
- Mean ROC-AUC: 0.767210
- Std ROC-AUC: 0.001418
- OOF ROC-AUC: 0.767191

相比之下，Regularized LightGBM 的结果为：

- Fixed validation ROC-AUC: 0.772396
- 5-fold CV mean ROC-AUC: 0.766092
- 5-fold CV std: 0.002189

两种模型在固定 validation split 上几乎完全一致
（0.772394 vs. 0.772396）。

但是在 five-fold cross-validation 中，XGBoost 的平均 ROC-AUC
略高，同时 fold-to-fold variability 更低。因此基于交叉验证结果，
最终选择 V1 XGBoost 作为当前 V1 pipeline 的 selected model。

XGBoost 五个 fold 的最佳 boosting rounds 为：

- 694
- 477
- 582
- 793
- 805

平均最佳 boosting rounds 为 670，因此最终使用全部训练数据重新训练
XGBoost 时设置：

`n_estimators = 670`

最终 XGBoost 参数为：

- objective = binary:logistic
- n_estimators = 670
- learning_rate = 0.03
- max_depth = 6
- subsample = 0.8
- colsample_bytree = 0.8
- reg_alpha = 0.1
- reg_lambda = 1.0
- tree_method = hist
- eval_metric = auc
- random_state = 42

最终模型使用全部 307,511 条有标签训练样本重新拟合。

## 6. Notebook

C 部分完整实验过程位于：

`notebooks/02_modeling.ipynb`

Notebook 中包含以下主要步骤：

1. 接入 A 部分的数据读取与固定 80/20 stratified split
2. 复现 V0 Logistic Regression baseline
3. 训练 V0 LightGBM baseline
4. 接入 B 部分的 EDA 与 feature-selection 结果
5. 构建 V1 raw feature set
6. 完成 V1 numerical preprocessing
7. 完成 V1 categorical preprocessing
8. 构建最终 83-feature numeric model matrix
9. 训练 V1 LightGBM baseline
10. 实现 leakage-safe five-fold stratified cross-validation
11. 进行 Regularized LightGBM 实验
12. 进行 class-weight / class-imbalance 实验
13. 比较 LightGBM 不同配置并完成初步模型选择
14. 使用全部训练数据训练 Regularized LightGBM
15. 生成并验证 LightGBM submission
16. 导出 LightGBM 和 C-part handoff results
17. 加入 XGBoost 作为第二种 gradient-boosting model
18. 在固定 80/20 validation split 上进行 XGBoost sanity check
19. 使用相同的 fold-safe preprocessing 进行 XGBoost five-fold CV
20. 比较 XGBoost 与 Regularized LightGBM 的 CV mean 和 variability
21. 根据 CV 结果选择 XGBoost 作为最终 selected model
22. 使用全部 307,511 条训练数据重新训练最终 XGBoost
23. 对官方 48,744 条 test data 生成 XGBoost predictions
24. 生成并验证 `submission_v2_xgboost.csv`
25. 导出 XGBoost CV、validation predictions、feature importance、
    model configuration 和最终 fitted model

整个 Notebook 保留了从 baseline 到最终模型选择的完整实验链，
用于保证建模过程具有可复现性，并支持最终报告中的模型比较与分析。
