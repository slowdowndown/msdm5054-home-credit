## 核心结论

120 个原始特征经筛选后进模型 66 个：

| 决策 | 数量 | 依据 |
|---|---|---|
| DROP 近常数 | 20 | ≥99% 单一值 |
| DROP 共线冗余 | 35 | \|r\| > 0.9 且 IV 低于代表列 |
| KEEP | 65 | IV 排名 + 树重要性交叉印证 |
| ADD 派生 | 1 | `ANNUITY_TO_CREDIT`，唯一优于两个父列的比值 |

要点：

- IV 集中于三个外部评分 `EXT_SOURCE_3`（0.330）、`EXT_SOURCE_2`（0.303）、`EXT_SOURCE_1`（0.151）。
- 树重要性（置换重要性，ROC AUC）与 IV 的 Spearman 秩相关 0.59，未发现被 IV 遗漏的强交互特征。
- `AMT_CREDIT` 被共线删除，其金额信号由派生特征 `ANNUITY_TO_CREDIT = AMT_ANNUITY / AMT_CREDIT` 吸收；计算用原始列，仅原始列不进模型。

## 与 V0 协议的关系

复用 SHU Yi 的 `src/data_pipeline.py` 中的 `fixed_split`（按 TARGET 分层，seed 42，80/20），不重拆。V1 特征变换以 `column_decisions.md` 为准，替代 V0 的简单预处理。两处口径差异：

| 项 | V0 预处理 | V1 约定 |
|---|---|---|
| log1p 金额 | income、credit、annuity、goods-price 四个 | 仅 income |
| 类别编码 | one-hot | 高基数 target encode，其余 label encode |
| 缺失 >80% | 直接 drop | 保留，missing indicator + bin |

log1p 差异的说明：树模型对金额的单调变换不敏感，credit/annuity/goods-price 的 log 在 V1 里非必需；仅当保留 LR baseline 对比时沿用 V0 的四字段 log。

## 复现步骤

环境为 Anaconda（scikit-learn 1.4.2、scipy 1.13.1），按依赖顺序：

```bash
cd msdm5054-home-credit

python scripts/eda/eda_univariate.py          # 近常数/稀疏/变换标志
python scripts/eda/eda_outliers.py            # 离群值
python scripts/eda/eda_deepen_1_5.py          # 缺失与泄漏
python scripts/eda/eda_relationships.py       # WoE/IV/关联/单调
python scripts/eda/eda_derived_iv.py          # 派生比值（依赖上一步）
python scripts/eda/eda_collinearity.py        # 共线性
python scripts/eda/eda_tree_importance.py     # 树重要性交叉印证（耗时较长）
python scripts/eda/make_column_decisions.py   # 列决策清单
python scripts/eda/make_eda_figures.py        # 图 00–27
```

机器可读的逐列清单见 `results/eda/column_decisions.csv`（列：`feature`、`decision`、`transform`、`reason`、`iv`、`type`）。
