# ZHANG Yajing：C 部分建模、交叉验证与调参交接说明

本部分负责 Home Credit Default Risk 项目的模型训练、交叉验证、模型比较与最终模型选择。

C 部分严格复用 A 部分提供的固定数据版本与 80%/20% 划分，并使用 B 部分提供的特征决策结果构建 V1 特征集。模型选择以 ROC-AUC 为主要评价指标。

## 2. 模型开发过程

模型开发从 A 部分 Logistic Regression baseline 开始，并逐步比较 LightGBM、V1 特征工程、交叉验证、正则化和类别权重。

主要结果如下：

| Experiment | Validation | ROC-AUC |
|---|---|---:|
| V0 Logistic Regression | Fixed 80/20 | 0.751239 |
| V0 LightGBM | Fixed 80/20 | 0.759364 |
| V1 LightGBM baseline | Fixed 80/20 | 0.769522 |
| V1 LightGBM baseline | 5-fold CV mean | 0.763755 |
| V1 Regularized LightGBM | 5-fold CV mean | 0.766092 |
| V1 Regularized + class weight | 5-fold CV mean | 0.765550 |
| Final V1 Regularized LightGBM | Fixed 80/20 | 0.772396 |

Regularized LightGBM 的 5-fold CV：

- Mean ROC-AUC: 0.766092
- Std ROC-AUC: 0.002189
- Best iterations: 659, 738, 660, 875, 593
- Mean best iteration: 705

类别权重 `scale_pos_weight` 经交叉验证后没有提升 ROC-AUC，因此最终模型不使用类别权重。

---

## 3. 最终模型

最终选择：

`V1 features + Regularized LightGBM`

最终参数：

- objective = binary
- n_estimators = 705
- learning_rate = 0.03
- num_leaves = 32
- subsample = 0.8
- subsample_freq = 1
- colsample_bytree = 0.8
- reg_alpha = 0.1
- reg_lambda = 0.1
- random_state = 42
- scale_pos_weight = not used

`n_estimators=705` 来自 regularized 5-fold cross-validation 的平均最佳迭代次数，而不是继续针对固定 validation set 调整。

最终模型重新使用全部 307,511 条有标签训练数据拟合。

## 5. C 部分输出文件

所有主要建模交接文件位于：

`results/c/`

### `model_summary.csv`

模型实验结果汇总，可直接用于报告中的模型比较表。

### `validation_predictions_v1.csv`

固定 validation set 的预测结果，包括：

- `SK_ID_CURR`
- `TARGET`
- `PRED_PROB`

该文件建议由 D 部分直接用于：

- ROC curve
- Precision-Recall curve
- confusion / threshold analysis
- calibration analysis
- additional validation metrics

无需重新训练模型。

### `cv_results.csv`

保存五折交叉验证结果，包括 baseline、regularized 和 class-weight experiments。

### `final_model_config.json`

保存最终模型参数和核心验证结果。

### `feature_importance.csv`

保存最终全量 LightGBM 模型的 feature importance，可用于模型解释和报告图表。

### `final_feature_names.json`

保存最终 83 个模型输入变量的准确顺序。

### `final_lightgbm_preprocessed_input.joblib`

保存最终全量训练后的 LightGBM 模型。

注意：该模型不能直接接收原始 `application_train.csv` 或 `application_test.csv`。

它需要与 C Notebook 相同的 V1 preprocessing 后的 83-feature numeric matrix。
