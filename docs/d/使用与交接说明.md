## 核实的模型选择依据

| 指标 | Regularized LightGBM | XGBoost |
|---|---:|---:|
| 固定验证 AUC（D 重算） | 0.772396 | 0.772394 |
| 五折 CV 均值 | 0.766092 | 0.767210 |
| 五折样本标准差（统一 ddof=1） | 0.002189 | 0.001586 |
| AP（D 重算） | 0.262523 | 0.261932 |

XGBoost 的 CV 均值高约 0.001118；固定验证集 AUC 基本相同，不能写“验证 AUC 显著提升”。C 的 XGBoost 标准差 0.001418 是 ddof=0，而 LightGBM 使用 ddof=1。D 在 cv_summary.csv 同时保留两种计算值，报告用统一的样本标准差；未改动 C 文件。

两份预测均为 61,503 行、正例 4,965；D 按 SK_ID_CURR 对齐，确认 ID 集与 TARGET 一致，不依赖文件行顺序。仍缺少原始数据，不能独立核对 canonical split 与真实标签来源。

## XGBoost 实际错误情况

- 阈值 0.50：TP=143、FP=105、FN=4,822、TN=56,433，召回率 2.88%。
- 阈值 0.10：TP=3,041、FP=12,474、FN=1,924、TN=44,064，召回率 61.25%。
- 阈值 0.10 相比 LightGBM 多识别 40 个正例，也多误报 217 个负例。
- 最高风险约 10% 的客户包含 35.69% 的全部正例，正例率为 28.81%。

阈值只是教学/描述性示例，不是优化后的业务决策规则。默认 0.50 的准确率约 91.99%，但全判正常已有 91.93%，因此不能只看 Accuracy。

## 拟合模型不能混写

- LightGBM 验证模型：892 轮；另一个全量模型：705 轮。
- XGBoost 验证模型：best_iteration=777 是零起始索引，即 778 轮；另一个全量模型：670 轮。
- 两个验证模型都使用该验证集早停，指标不是独立测试成绩。
- XGBoost 文件名 submission_v2_xgboost.csv 仍使用 V1 特征，不代表完成多表 V2 特征。
- XGBoost 重要性为归一化 gain，LightGBM 为 split count，数值不可直接跨模型比较；两者都不是 SHAP。
