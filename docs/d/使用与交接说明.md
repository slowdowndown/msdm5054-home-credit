## 口径纠正与局限

C Notebook 第 15 节在固定验证集早停到 892 轮，导出的 validation_predictions_v1.csv 来自该模型。第 17 节全量重训采用 705 轮；两者不是同一个拟合模型。固定验证 AUC 不应归于 705 轮全量模型。

C 内部 CV 在 80% 训练集内执行；预处理按折拟合，但 B 的特征筛选已使用整个 80% 训练集。且 corrected weighted 实验显式仅用 AUC 早停，其他 CV 配置没有同样限定。以上限制已写入报告，不擅自修改 C。

D 已检查 ID 唯一性及预测格式，但原始数据不在仓库快照中，无法独立确认 canonical split 成员与标签。原始特征分组分析、跨模型配对检验和 SHAP 尚未进行。当前 error analysis 是真实的分数分组与漏判/误判分析。
